                            OVERVIEW
=============================================================================

This document tracks all feature selection processes, methods, and results
for the Mental Health Analyzer project. Feature selection is crucial for:
- Improving model performance by reducing noise
- Reducing computational complexity
- Enhancing model interpretability
- Preventing overfitting

=============================================================================
                        CURRENT DATASET ANALYSIS
=============================================================================

Dataset Location: artifacts/data.csv
Total Features: 13 (excluding target)
Target Variable: IsCounselingNeeded (binary: 0/1)

FEATURE LIST:
1. Gender (Categorical) - Male/Female
2. Age (Numerical) - Student age
3. CGPA (Numerical) - Cumulative Grade Point Average
4. Depression (Binary) - 0/1 indicator
5. Anxiety (Binary) - 0/1 indicator  
6. PanicAttack (Binary) - 0/1 indicator
7. SpecialistTreatment (Binary) - 0/1 indicator
8. SymptomFrequency_Last7Days (Numerical) - 0-7 scale
9. HasMentalHealthSupport (Binary) - 0/1 indicator
10. SleepQuality (Numerical) - 1-5 scale
11. StudyStressLevel (Numerical) - 1-5 scale
12. StudyHoursPerWeek (Numerical) - Hours per week
13. AcademicEngagement (Numerical) - 1-5 scale

TARGET VARIABLE CHARACTERISTICS:
- Based on rule-based logic combining multiple indicators
- Highly imbalanced (mostly 1s - counseling needed)
- Created from: Depression OR Anxiety OR PanicAttack OR SpecialistTreatment 
  OR SymptomFrequency >= 3 OR (no support AND poor sleep/high stress) 
  OR CGPA <= 2.5 OR AcademicEngagement <= 2

=============================================================================
                    FEATURE SELECTION METHODS TO IMPLEMENT
=============================================================================

1. STATISTICAL METHODS:
   - Chi-Square Test (for categorical features)
   - ANOVA F-test (for numerical features)
   - Mutual Information

2. CORRELATION-BASED:
   - Pearson Correlation with target
   - Feature-to-feature correlation (multicollinearity detection)

3. MODEL-BASED METHODS:
   - Recursive Feature Elimination (RFE)
   - LASSO Regularization (L1)
   - Tree-based feature importance (Random Forest, XGBoost)

4. WRAPPER METHODS:
   - Forward Selection
   - Backward Elimination
   - Exhaustive Feature Selection

5. ENSEMBLE METHODS:
   - Combine multiple methods for robust selection
